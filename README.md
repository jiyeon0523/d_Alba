# d’Alba 반응형 메인

React 19 · TypeScript · Vite 8 · Tailwind CSS 4

## 실행

```sh
pnpm install
pnpm dev
```

Figma Make에서는 개발 서버가 이미 실행 중이며, 미리보기 패널에서 바로 확인할 수 있습니다.

```sh
pnpm build
pnpm preview
```

## 파일 구조

- `src/App.tsx`: 메인 섹션, 제품 검색, 장바구니, 선케어 추천, 접근 가능한 공통 다이얼로그
- `src/components.tsx`: 헤더/GNB, 히어로 슬라이더, 제품 카드, 탭, 버튼, 이미지 로딩 실패 처리
- `src/data.ts`: Figma의 제품, 컬렉션, 루틴 데이터
- `src/index.css`: 원본 폰트, Tailwind 설정, 페이지네이션 진행 애니메이션
- `public/assets/`: 다운로드한 Figma 원본 이미지와 SVG

## 구현 범위

PC 메인과 연결된 컴포넌트 시안을 기준으로 구현했습니다. 제공된 링크에서 별도 모바일 메인 프레임은 확인되지 않아, 모바일은 동일 콘텐츠를 햄버거/아코디언 메뉴와 터치 스크롤 구조로 재배치했습니다. 정확한 모바일 시안 비교를 위해서는 해당 프레임 링크가 추가로 필요합니다.

자동 배너는 5초 간격으로 진행하며, 복제 슬라이드에서 위치를 무전환 초기화하여 마지막에서 첫 배너로 앞으로 이어집니다. 키보드 포커스가 배너에 있는 동안 자동 전환을 중지합니다.

장바구니는 현재 브라우저의 localStorage에만 저장됩니다. 실제 주문, 결제, 회원 계정 및 서버 저장은 연결하지 않았습니다. 제공되지 않은 상세 페이지와 외부 링크는 임의로 만들지 않고 미연결 안내를 표시합니다. 선케어 추천은 선택형 데모이며 의학적 진단이 아닙니다.
